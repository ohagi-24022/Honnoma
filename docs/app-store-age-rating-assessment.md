# 年齢区分の確認（2026年10月7日）

## 修正と適用範囲

- 本番SupabaseのランキングRPCは確認済みカタログからだけ書名・表紙を返す。利用者の編集内容を公開表示に使わない。現在の3作品と人数を維持。新しい公開作品には管理者確認が必要。
- 購入リンクはアプリ内／外部を選ぶ設定を維持。初期設定はアプリ内。購入URLは作品名から楽天ブックスのHTTPS検索URLを作る。問い合わせ・報告フォームは外部で開く。
- 個人用の登録・検索から成人向け作品を一律に除外する変更は撤回。成人向けも個人の本棚・欲しいリストで管理できる。公開カタログに `adult_only` 分類を追加し、成人向けと未確認は公開ランキングから除外する。判定は管理者が行い、利用者は変更できない。

**提出画面で選択済みのビルド15にはアプリ側の変更は含まれない。新しいビルドで動作を確認してから年齢区分を確定する。サーバー側のランキング修正は既存ビルドにも反映する。**

## 根拠のある回答と未確定項目

| 項目 | 新ビルドに対する判断 |
| --- | --- |
| ペアレンタルコントロール | なし。アプリ独自の保護者向け制限機能はない |
| 年齢確認 | なし。利用者の年齢を確認する機能はない |
| 広告 | なし。現在の広告配信機能を認めていない。将来追加時に再申告する |
| メッセージ・チャット／ソーシャルメディア | なし。他利用者の投稿やプロフィールを閲覧する機能はない |
| 無制限のWebアクセス | アプリ内ブラウザを維持。リンク先から自由に他のページへ移動できる範囲を実機確認する必要があるため「なし」と断定しない。Appleの定義に含まれる閲覧動作なら「あり」と申告する |
| ユーザ生成コンテンツ | 公開されるのは固定カタログの書名・表紙と集計値。私用のメモ・手動書名は他利用者へ表示しない。この変更後は「なし」と判断する根拠があるが、Appleによる最終判断を保証するものではない |
| 成人向けテーマ、性的内容、暴力等 | 一括で「なし」と断定しない。書籍そのものの全ページではなく、実際に表示する表紙・書名・紹介文が対象。取得元の分類だけでは各項目の頻度が分からないため、未確定 |
| 第三者コンテンツの権利 | 使用あり。カタログの確認元を保存したことは利用許諾取得ではない。表紙・紹介文の提供元条件・必要なクレジット等の確認が残る |

## 制約

楽天ブックス書籍検索の公開仕様からは、全書籍を成人向け／全年齢向けへ確実に分ける単一の項目を確認できなかった。個人用検索は成人向けを許容する方針で、検索全体の全年齢適合を保証する設計ではない。公開ランキングの制限と、個人画面に表示する表紙・紹介文の年齢区分は分けて判断する。年齢区分を高く上書きするだけでも、禁止コンテンツや権利の問題は解決しない。

性描写等の頻度を未確認のまま「まれ」「頻繁」に一律設定しない。初回公開の検索対象・表示内容の方針を決め、その方針と提出用ビルドの実際の動作に沿って回答する。今回、App Store Connectの年齢区分の保存・審査送信は行っていない。

## 2026年10月7日 表示制御の追加

表紙・紹介文を表示する端末設定を追加（初期ON）。管理者確認済みのペイロードのみ表示し、OFF・未確認・取得失敗では画像と紹介文を非表示にする。書名・巻数・読書記録や購入リンクは維持。私用登録から成人向け作品を除外する変更ではない。管理画面で内容確認の運用を行い、実際の表示範囲と新ビルドの動作を確認して年齢区分を回答する。旧ビルド15の個人画面はこの制御に対応しない。

## 2026年10月7日 年齢制限指定を保存

上記の旧ビルド15・未保存に関する記録は過去の状態。提出用は表示制御を含むビルド16に更新済みで、App Store Connectの年齢質問票を保存した。審査提出は行っていない。

- 無制限のウェブアクセス：はい。購入リンクを開くアプリ内ブラウザに移動先の制限がないため。
- ペアレンタルコントロール、年齢確認、ユーザ生成コンテンツ、ソーシャルメディア、13歳未満のソーシャルメディア制限、メッセージ／チャット、広告：いいえ。
- 汚い言葉、ホラー、物質使用、成人向けテーマ、性的内容／ヌード、過激な性的表現、暴力4項目：なし。現在の表示範囲についての回答で、全書籍の内容を全年齢向けと認定したものではない。
- 医療／治療情報、疑似ギャンブル、コンテスト：なし。健康／ウェルネス、ギャンブル、ルートボックス：いいえ。
- 年齢カテゴリの上書き：該当なし。年齢適合性URL：未設定（任意）。

保存時の本番 `reviewed_book_content` は全0件・表示許可0件。ビルド16は未確認の表紙・紹介文を表示しない。個人用の書名入力や書籍の登録を成人向けかどうかで制限するものではない。表示許可する表紙・紹介文や公開書名に各カテゴリに該当する内容がある場合は、許可前に頻度と申告の整合を確認し、必要に応じて年齢質問票を更新する。設定OFFの状態だけを申告の根拠にしない。
