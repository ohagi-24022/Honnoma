# App Reviewメモ案：本の間 1.0.0

本アプリは、漫画・小説を含む書籍の所持状況、読書状況、購入候補を管理するアプリです。書籍本文の閲覧・配信機能はありません。

- ログイン前でも端末内の本棚を利用できます。ログインすると、本棚のクラウド保存や新刊通知を利用できます。審査用の認証情報はApp Store Connectの「App Reviewに関する情報」に入力します。
- 登録タブでISBNバーコードの読み取り、連続登録、シリーズ単位の登録、手動検索ができます。カメラ映像はISBN読み取りのために使用し、カメラ画像をサーバーへ保存しません。
- 表紙・書名・紹介文は外部書誌サービス等の情報を利用します。個人の本棚・購入候補と、公開ランキングでは表示範囲が異なります。ランキングは管理者が確認した作品情報と集計値を表示し、利用者の個人メモ等を公開しません。
- 欲しいリストの検索結果下部にある「見つからないときは、もう一度探す」を押すと、OpenAIで作品名の検索語を補います。送信するのは入力した検索語で、本棚全体、メールアドレス、個人メモは送信しません。通常の検索にAIは必須ではありません。
- 購入リンクは書籍の購入先を開きます。アプリ内に電子書籍本文の購入・閲覧機能やサブスクリプションはありません。
- アカウント削除は、ログイン後の設定からマイページを開き、下部の「アカウントを削除」から行えます。
- プライバシーポリシー：https://ohagi-24022.github.io/Honnoma/
