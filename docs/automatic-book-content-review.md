# 表紙・紹介文の自動確認

2026-10-07 実装。初期状態は停止中。OpenAI APIキーとSMTPパスワードを設定してから管理画面で有効にする。

## 動き

- アプリから送るのはISBNのみ。サーバーが楽天ブックス、openBD、Google BooksからISBNが完全一致する書籍データを取得する。利用者のメモ・アカウント・読書履歴はAIへ送らない。
- タイトル・実際の表紙画像・紹介文を別々に確認。曖昧な判定や表示に適さない可能性があるものは管理者の確認待ちへ。確認できた項目だけ表示する。
- 承認した画像は取得時のデータを保存し、外部URLの画像が後から変わっても表示内容を変更しない。
- 管理者が保存した内容は自動処理で上書きしない。公開ランキングは従来の掲載管理で別途確認する。
- 同じ内容の判定を再利用。処理は1日最大50件（再試行を含む）。公開窓口で新しく追加できる待ち列は1日最大1000件。
- 失敗は時間を空けて再試行し、5回失敗すると確認待ちへ。新しい確認待ちは15分間隔、最大20件のメールにまとめる。同一ISBN・内容の重複通知を抑止する。
- SMTP受付後の保存に失敗した場合など、完全な一度限りの配信は保証しない。同じ通知のメールIDを固定し、重複を抑える。
- 新規登録・メタデータ取得が待ち列追加のきっかけ。未処理がある場合だけ2分間隔でRenderを起動する。無料プランの休止や混雑、日次上限により、すぐに表示されない場合がある。

## 初回設定

RenderのShushukaAdminのEnvironmentに直接入力する。APIキー・パスワードをチャットやアプリの環境変数へ入れない。

| 名前 | 設定内容 |
| --- | --- |
| OPENAI_API_KEY | OpenAI Platformで作成したキー |
| CONTENT_REVIEW_MODEL | gpt-4.1-mini-2025-04-14 |
| CONTENT_REVIEW_SMTP_HOST | smtp.gmail.com |
| CONTENT_REVIEW_SMTP_PORT | 465 |
| CONTENT_REVIEW_SMTP_USER | ohagiworks.contact@gmail.com |
| CONTENT_REVIEW_SMTP_PASSWORD | Gmailのアプリパスワード |
| CONTENT_REVIEW_MAIL_FROM | ohagiworks.contact@gmail.com |
| CONTENT_REVIEW_MAIL_TO | ohagiworks.contact@gmail.com |

保存・再デプロイ後、管理画面の「自動確認・確認待ち」でAPIとメールが設定済みになったことを確認し、有効にする。初回は処理上限を1件にして判定内容と実際のメール配送を確認し、確認後に50件へ戻す。実際のAI判定品質とメール配送はキー未設定の間は未確認。

OpenAIのAPI利用料はChatGPTの契約とは別。Platformで支払い設定を行い、利用状況を確認する。アプリ側の件数制限は、この機能以外のAPI利用料金には適用されない。

## 検証

`node scripts/test-automatic-content-review.mjs`：ISBN一致、画像ホスト・データ検証、項目ごとの保留、AIの不完全回答、キー未設定、メール成功・失敗を模擬確認。

本番DBでテスト用トランザクションをロールバックし、処理の占有、日次上限、通知の一意性と間隔、古い確認画面からの保存拒否、クライアント権限制限を検証済み。

## 反映先

管理アプリの`content-review.mjs`と`review-admin.mjs`に、BookNestの`scripts/shushuka-*.mjs`を配置する。後者のimportは配置先の名前へ変更する。既存ビルド16もISBN登録・既存のメタデータ窓口経由でキューに追加できる。ゲストの表示中の本から直接再確認を依頼する変更は、次のアプリビルドに含まれる。

## API料金の試算（2026-10-07）

公式単価：GPT-4.1 miniは入力100万トークン0.40ドル、出力100万トークン1.60ドル。画像も入力トークンとして課金される。1処理あたり画像・説明・指示を合わせた入力1000〜5000トークン、出力200〜600トークンを仮定すると、0.00072〜0.00296ドル。1ドル150円という仮定で約0.1〜0.5円。106件なら約10〜50円、毎日50件を30日間処理した場合は約150〜750円。実測ではなく通常の長さの紹介文を想定した試算であり、長文・再試行・為替・税金で変わる。サーバーと画像保存の費用は含まない。日次件数制限は金額上限ではない。

公式料金：https://developers.openai.com/api/docs/models/gpt-4.1-mini
画像の課金：https://developers.openai.com/api/docs/guides/images-vision
