# 公開ランキングの作品情報

2026年10月7日、公開ランキングの名前と表紙を利用者の入力から切り離した。
`public.public_ranking_catalog` の有効な作品だけを公開し、所持・欲しい・お気に入りの件数を作品キーで結び付ける。3人以上の公開条件と、5人未満のスコア非公開は維持する。個人の本棚・欲しいリストは制限しない。

初期カタログは現在の公開対象3作品。漫画以外の書籍も追加可能。新しい作品は利用者が登録しても自動公開されない。管理者が書名・ISBN・表示する表紙・取得元を確認して追加する。個人の登録内容、共有メタデータキャッシュ、未知の画像URLをそのまま有効化しない。

## 追加・停止

個人の本棚・欲しいリストには成人向け作品も登録可能。公開ランキングだけを制限する。公開の条件は `enabled=true` かつ `adult_only=false`。`adult_only=true` は成人向け専用、NULLは未確認であり、どちらも公開しない。判定は管理者が行い、利用者は変更できない。falseは全年齢向けの認定を意味しない。

SupabaseのTable Editorで `public_ranking_catalog` を管理する。一般利用者のAPIキーでは変更できない。秘密のサービスキーをアプリへ組み込まない。

- `ranking_key`：集計で使用するキー。SQLの正規化結果に合わせる。表示名と分けて管理する。
- `title`：確認した正式な書名またはシリーズ名。
- `isbn`：確認の根拠となる13桁ISBN。
- `cover_url`：確認した表紙のHTTPS URL。表紙を掲載しない場合はNULL。
- `source_url`：確認元のHTTPS URL。
- `reviewed_at`：確認日時。
- `enabled`：確認完了後にtrue。停止する時はfalse。
- `adult_only`：成人向け専用はtrue、成人向け専用ではないと確認済みならfalse、未確認ならNULL。

ISBN確認とカタログへの追加は、著作権・提供元利用規約の許諾や全年齢向けの認定を意味しない。掲載条件と内容の確認は別途必要。

## 確認済み

追加検証：成人向け／未確認へ変更した作品が総合集計とお気に入りランキングから消えること、匿名・ログイン利用者によるカタログ取得にも出ないこと、個人の本棚が変化しないことを確認。テスト用変更はすべて取り消した。

本番で3作品と集計件数が維持されること、表示がカタログに従うこと、無効にした作品が公開RPCと一般利用者の取得結果に出ないこと、一般利用者によるカタログ追加が拒否されることを検証した。検証用変更はトランザクションを取り消し、残していない。

セキュリティ診断には、未ログインでも集計RPCを実行できる旨の注意が出る。これは既存の公開ランキング用途として意図した権限。個人の本棚を直接読み取れる権限は付与していない。
