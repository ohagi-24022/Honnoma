## 依存関係のセキュリティ確認

npm auditのCriticalはshell-quote更新で解消。最終依存構成は23警告（High 20 / Moderate 3、開発ツールと依存先への波及を含む件数）。audit fix --forceによるSDKの逆行や破壊的変更は適用していない。

- braces: 再帰パターンでのスタック枯渇。上流修正版なし。主にMetro等のパターン処理経由。https://github.com/advisories/GHSA-vfj7-8cjw-p6xm
- node-forge: RSA署名検証の問題。上流修正版なし。Expo署名関連の依存。アプリの認証コードが直接利用するものではない。https://github.com/advisories/GHSA-86w9-cpqp-85rv
- decode-uri-component: 不正URIのデコードによる処理時間増大。expo-router → query-string経由でランタイムに含まれる。修正版0.5.0はES Modulesに変更されており、CommonJSの既存呼出しに無検証で強制適用していない。ビルド19の後に、公式v0.5.0の線形デコーダー部分を既存CommonJS版へバックポート。patch-packageでインストール時に適用し、不正リンクの時間制限付き回帰テスト・正常な日本語/認証パラメータの互換テストを追加。バージョン表示が0.2.2のため監査警告自体は残る。https://github.com/advisories/GHSA-vcc3-ghjq-m6fr

ビルド19は上記URI修正前のため提出対象から除外。修正を含むビルド20へ更新する。未修正の開発ツール側警告をゼロとは報告しない。ストア審査へは自動送信しない。
