# Expo Go SDK 58 compatibility

Updated the local app from Expo SDK 57 to SDK 58 after the store version of
Expo Go moved to SDK 58. No EAS build, OTA publish, or App Store submission.

- Expo 58.0.21 / Router 58.0.28 / React Native 0.88.0 / React 19.3.0.
- Matched camera, notifications, gesture handler, Reanimated, Worklets, and
  other SDK packages to the official online compatibility check.
- Migrated ScrollView refs to ScrollViewInstance, empty FlatList components
  to undefined, and tab icon colors to the app's existing theme strings.
- Removed the obsolete decode-uri-component patch and patch-package hook:
  Router 58 no longer includes query-string or decode-uri-component.
  Kept malformed-link and authentication parameter regression checks using
  the actual Router 58 URL helpers.
- Kept Supabase client 2.108.2 and CLI 2.109.0 at their previous resolved
  versions; this upgrade does not change server behavior.

Verification:

- Expo Doctor: 20/20 checks passed.
- TypeScript: passed.
- Existing regression scripts: 43/43 passed.
- iOS and Android JavaScript export: passed (local temporary files only).
- Restarted this project's existing Metro on port 8081 with --go --clear.
- Both platform manifests returned HTTP 200 and sdkVersion 58.0.0;
  both development bundle requests returned HTTP 200.
- Physical-device visual interaction still requires the user's Expo Go check.
