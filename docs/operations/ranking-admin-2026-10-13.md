# ランキング掲載管理の改善

- 管理アプリの準備済みコミット: `1ca4355`。変更は `content-admin.mjs` と新規 `ranking-admin.mjs` のみ。
- ユーザーの今回の公開承認後、mainへ反映済み。Renderデプロイ `dep-db71bqe7bikc73fo2gag` はliveを確認。更新開始以降のerrorログは0件。ランキングルートの応答と管理者認証の維持を確認した。ログイン後の実データを使った画面操作はこの公開確認では行っていない。
- 表紙・タイトルを横並びにし、掲載／非掲載をラジオボタンで変更。一般向けの候補は一覧から追加可能。
- 確認用データをシリーズでまとめ、最小巻数を代表巻として選択。表紙は確認済みの公開画像のみ自動入力する。
- 検索、掲載状態フィルター、10/30/50/100件とページ移動。表示件数をcookieで保持し、保存後も検索条件とページを維持する。
- 一括掲載選択・取り消し・まとめて保存。選択と保存は別。成人向けと未確認は一括掲載対象外。
- 編集では作品名・代表ISBN・一般向け／成人向け・掲載設定を操作。キーとURLは詳細欄へ移動。
- 既存の掲載状態は変更された行だけ保存。更新日時とISBNで同時編集の競合を検出し、途中失敗時は保存件数と一覧へのリンクを示す。候補追加時は既存の同キーを上書きしない。
- スキーマ変更はなし。順位の集計条件や個人の本棚データは変更していない。

検証: `node scripts/test-ranking-admin.mjs`、`node scripts/test-content-admin.mjs`、管理アプリのモジュール読込と構文検査。1000件超の取得・検索も検証。ローカルの書き込み不可の見本で一覧と一括選択を確認。
